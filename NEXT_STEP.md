# GovVendor v1.0 portfolio package

This clean source bundle combines the **Gulf Trading LLC** homepage and charcoal navigation with a concise README, full project guide, and demo recording script.

1. Extract the ZIP into a separate folder.
2. Follow [START_HERE.md](START_HERE.md) to run it on Windows, or use the local setup commands in [README.md](README.md).
3. Open **Demo walkthrough** from Home to try submission, assignment, approval and renewal.
4. Use [PUBLISH.md](PUBLISH.md) when you are ready to put the source on GitHub, and [DEMO_SCRIPT.md](DEMO_SCRIPT.md) to prepare a short demo.

The bundle does not include local accounts, applications, or uploaded documents.
